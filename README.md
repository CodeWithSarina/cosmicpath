# CosmicPath

**CosmicPath** is a modern astrology and horoscope website that provides personalized astrology insights, zodiac analysis, kundali readings, and daily horoscopes. Users can explore their cosmic path with precision birth-chart tools and interact with an AI astrology assistant.

---

## 🌟 Features

- **Personalized Horoscopes:** Daily, weekly, and monthly predictions tailored to each user.
- **Zodiac Insights:** Detailed analysis of sun signs, traits, and life path.
- **Kundali Readings:** Generate and view birth charts for deeper astrology insights.
- **AI Astrology Assistant:** Ask questions and receive instant guidance.
- **User Profiles:** Save your birth details and track personalized insights.
- **Interactive Zodiac Wheel:** Visual representation of zodiac signs and planetary positions.

---

## 🖥️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Fonts & Icons:** Google Fonts (Poppins), Unicode Zodiac Symbols  
- **Hosting:** GitHub Pages (static website)  
- **SEO Optimized:** Meta tags, sitemap.xml, robots.txt, canonical URLs, Open Graph & Twitter cards
